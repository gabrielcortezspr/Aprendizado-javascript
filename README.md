# Aprendizado JavaScript

Minhas anotações e exercícios do curso **"Aprenda JavaScript com facilidade do zero"**, do
Prof. Ivan Lourenço Gomes. São 53 aulas em HTML, cada uma com o código comentado e o resultado
na própria página.

## Conteúdo

| Aulas | Tema |
|---|---|
| 01–08 | Sintaxe, variáveis e tipos de dados |
| 09–18 | DOM, funções, arrays, objetos, eventos e CSS |
| 19–32 | Loops, condicionais, BOM, `localStorage`, datas, formulários |
| 33–42 | jQuery: seletores, manipulação, eventos, efeitos e animações |
| 43–53 | Callbacks, tratamento de erro, escopo, JSON e AJAX |

Aulas terminadas em `exercicio` são os exercícios práticos de cada bloco.

## Como ver

Abra [`01-primeiros-passos.html`](01-primeiros-passos.html) no navegador; o índice de
navegação entre as aulas é montado por `tools/indice.js`.
